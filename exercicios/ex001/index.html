identificando cada tag:

<p> é a tag de parágrafo;

<hr> é a tag de linha;

<h1> é a tag de titulo do site;

<title> é a tag de nome da aba;

entre <head>e <head> é onde todo comando que fica por tras do site

entre <body> e <body> é onde fica todo o corpo do site, a parte visual dele

<br> é a tag de quebra de linha
